## Approved correction boundaries

1. Preserve original fixtures/reports; create a corrected fixture and independent saved-response rescore. Correct expectations only with the reasoning above. Phrase matching must not use predicted authority/domain/population as prerequisites, because doing so hides dimension errors. Maximum one-to-one matching must not count a merged employer/employee issue as two answers. Add aliases for meaning, not entire saved labels.
2. Refine the generic prompt: distinguish requested outcomes from facts already stated; distinguish employer role from company taxpayer; require numerical operations for requested amounts, journal operations for requested entries; do not label unrelated requested treatments EXPLAIN_INTERACTION. Keep UNKNOWN when role or scope is unspecified.
3. In the planner, keep mapped topic priority, but remove the population-only EMPLOYEE=>benefit assumption. For topicless issues, distinguish personal relief/salary, employment benefits and explicit employer reporting from the subject; ambiguous subjects remain UNKNOWN. Subject interpretation must not manufacture topic support or evidence.
4. Keep UNASSIGNED_QUERY_TOPIC residuals visible and whole-question evidence incomplete, while preventing them from creating new requested authority streams. Contextual accounting should not cause legacy classification/accounting processing to request journals when validated issues request only tax. Preserve fallback behaviour for providers without issues.
5. Freeze a separate held-out set before live measurement. Use no live calls while developing. Record corrected saved scoring, deterministic replay and new live measurements as separate modes. All provider failures remain in attempt history. Local evidence tests do not establish live source freshness or substantive tax-answer correctness.

Next source coverage: first repair the semantic/taxonomy boundary. A narrowly scoped review of employee personal-tax relief topic recognition is more justified than broad new statutory packs; the existing relief sources must pass admission and freshness checks. No coverage expansion is authorized by this audit.
