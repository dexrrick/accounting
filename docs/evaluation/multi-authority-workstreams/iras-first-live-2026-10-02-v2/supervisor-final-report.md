Raw responses were intentionally not retained, so failed semantic dimensions cannot be reconstructed from these safe artifacts. No retrospective adjudication or tuning followed observation.
8. **Timeout decision.** RETAIN 8,000 ms; production is unchanged. The reviewer independently recomputed this decision. Neither longer arm supplied any valid completion beyond 8 seconds or reduced timeout count, so neither meets the preregistered increase criteria. Six observations per arm are a limited pilot, not statistical proof; they do not establish that rare tail delays or the v1 timeouts cannot recur. Schema complexity is constant, so its latency effect is not identifiable. Among 18 received responses, descriptive Pearson correlations with completion latency were prompt length r=0.769, issue count r=0.664, and output bytes r=0.788. These are confounded by three fixed case types and small samples; they support no causal or timeout-policy claim. The two-issue CPF/relief prompt averaged 2,482.08 ms, versus residency 2,077.92 and IFRS/Singapore accounting 2,281.89 ms; all are well below the existing deadline.
