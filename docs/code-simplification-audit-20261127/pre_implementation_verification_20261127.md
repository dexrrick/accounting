## 1. Executive Summary

Forensic code inspection and offline / mocked-provider reproduction against `origin/main` (`348dd7b`) establish three high-priority conclusions:

1. **Multiple AUD-10 and AUD-11 hardcoded benchmark amounts, dates, FX rates, and offline narrative templates are CONFIRMED PRODUCTION DEFECTS—not unreachable offline legacy code.** Because [`processAccountingQueryCore`](../../src/services/geminiService.ts#L1394-L1422) runs [`parseAccountingQuery`](../../src/engine/scenarioParser.ts#L228) before invoking an AI provider and short-circuits balanced deterministic journals directly to [`renderStructuredOfflineResponse`](../../src/services/geminiService.ts#L1617-L2223)—and because [`assembleDeterministicResponse`](../../src/engine/responseAssembler.ts#L434-L440) / [`postProcessAIResponse`](../../src/services/groundingContextBuilder.ts#L3643-L3647) overwrite AI outputs when `hasAuthoritativeDeterministicEntries` is true—hardcoded amounts reach **both online AI-provider users and offline users**, bypass [`validateJournalGroups`](../../src/verification/journalIntegrity.ts#L122), and get **committed to the user's ledger** via [`updateCommittedJournalScenario`](../../src/services/committedJournal.ts#L9-L32).
2. **Pending Codex branch `codex/review-fx-request-deadline-20261126` (`15bff66`) already resolves the entire `EQUITY_INVESTMENT_FX` hardcoded-rate/date defect chain** (across `scenarioParser.ts`, `accountingEngine.ts`, `frankfurterService.ts`, and `geminiService.ts:renderStructuredOfflineResponse`) and adds request-deadline timeouts to `extractEventSequenceWithGemini`. **However, zero pending branches resolve `PPE_IAS16`, `ASSET_PURCHASE_DISCOUNT`, `PAYROLL_CPF_SALARY`, `LEASE_IFRS16` hardcoded dates, or the `validateJournalGroups` / `committedJournal` integrity gaps.**
3. **Several original Batch 1 / AUD-12 recommendations require scope refinement** after code and test verification:
   - `buildGroundingEvidenceTrace` (`groundingContextBuilder.ts:2887`) and `corporateTaxTreatment.ts` are **actively used in production** (false positives in AUD-12; must **not** be removed).
   - Gating `extractEventSequenceWithGemini`, setting `maxOutputTokens`/`thinkingBudget`, moving `interpretSemanticQuestion`'s `RESPONSE_SCHEMA`, and changing `azureOpenAiService.ts` history or `makePacketForPrompt` are **behaviour-affecting** (and several break existing regression assertions) and must be separated from strictly behaviour-preserving Batch 1 optimisations.
