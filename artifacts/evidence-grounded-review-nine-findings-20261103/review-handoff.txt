## Changes and finding coverage

1. Unresolved applicability and missing facts constrain APPLICATION claims deterministically. Conditional wording is checked by clause, so an earlier modal cannot authorize a later categorical outcome. A positive model-review verdict cannot bypass this check.
2. Posting-intent checks cover Dr/Cr pairs, account-line forms, posting verbs, arbitrary account names, and standalone debit/credit imperatives. Ordinary credit-note/balance narration has positive controls. Existing engine-backed non-posting accounting narration remains supported.
3. Numerical claims require complete normalized source wording or narrowly matched affirmative deterministic GST field narration, retaining field identity, currency, percentage and sign. User numbers support only explicitly attributed copied factual limitations. Provision matching retains alphabetic subclauses. Tests reject reused question numbers, adjacent unrelated rates, swapped calculation fields, negation, sign/date relabeling and invented subclauses.
4. Failed answers can be retried only while their original request is the latest user turn. Both the App handler and ChatPanel enforce this. A regression invokes actual App handlers for A failing, B succeeding and retrying A; B's state/messages remain unchanged and no third service call occurs.
5. Evidence-gap IDs support LIMITATION claims only. SUPPORTED rule/application verdicts must confirm an admitted passage matching the claim's issue.
6. Trusted journal evidence requires explicit DETERMINISTIC authority, non-hypothetical status, positive finite totals and existing validateJournalGroups integrity checks. AI_PROPOSED, CONDITIONAL and unmarked groups are excluded.
7. Planned, contextual and workstream issues are retained. Each requested issue needs an appropriate supported claim or an explicit per-issue limitation. An accounting-domain issue can be satisfied by its supported ACCOUNTING claim; a generic rule alone does not satisfy a case-application request.
8. Targeted repair reviews only repaired claims. Initially supported text and its original verdict are preserved when the repaired set is combined.
9. A new accounting scenario prunes history before grounding and informs synthesis through the same boundary callback. A production-entry mixed accounting/IRAS regression excludes earlier conflicting facts.
